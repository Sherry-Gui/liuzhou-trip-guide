🌙 抵达夜｜胜利烧烤城

22:50后本地夜宵组合两人分食
约 ¥90–140
  1. 小卢炒螺 · 小份炒螺蛳粉 1份胜利夜市常见的本地夜宵吃法，锅气和酸笋味比“摆盘网红小吃”更重要；两人分一份，要求少辣。
  2. 小卢炒螺 · 炒鸭脚或炒田螺二选一炒鸭脚偏软烂酸辣，炒田螺更适合慢慢嗍；不要两个都点，避免和炒粉一起过量。
  3. 四季豆浆 · 原味豆浆 2杯＋油条 1根就在夜市一带，用清淡豆浆压住炒粉的辣和油，比继续叠加烧烤更像柳州人的夜宵搭配。
  4. 叮当炒冰 · 芒果或牛油果 1杯只选一个口味。炒冰是胜利夜市代表甜口，但第一晚已很晚，排队超过25分钟就放弃。
两人照着点：小炒粉＋炒鸭脚/炒田螺二选一＋两杯豆浆；还有胃口再加一杯炒冰。不点外地夜市通用的飞饼、烤冷面和大盘烧烤。

☀️ 早市尾场｜青云民生市场

11:35–12:20看到先买可能售罄
约 ¥45–75
  1. 张记回头客玉米汁 · 2杯现榨过筛，热饮可选有糖或无糖。11点后先买它，卖完就不在市场里来回找。
  2. 桂姐小吃 · 糯米饭或露水汤圆二选一糯米饭选粉蒸肉＋腊肠；露水汤圆是咸肉馅粘米皮。两样都吃会太顶，留胃给下午。
  3. 十八婶 · 芝麻花生糊 1碗手工糊是青云市场更稳定的老派甜口，两人共享一碗；若摊位已收档，直接跳过。
  4. 潘家豆粉馍 · 2个黄豆粉香、甜度低，属于广西市场型小吃。买到现做的再吃，冷硬的不要勉强打卡。
  5. 杨嫂豆花 · 三拼 1碗，作为替补豆花＋糯玉米＋槐花粉。前面摊位售罄时再选，不与芝麻糊同时点。
11点尾场策略：玉米汁 → 桂姐二选一 → 芝麻糊/豆花二选一 → 豆粉馍。12:20离场；青云是菜市场，不要为了凑“网红全套”拖延去龙潭公园。

🌆 主力逛吃｜五星街＋金鱼巷

17:00开始一碗主食甜咸交替
约 ¥80–130
  1. 文惠桥头大华干捞粉 · 2两＋卤蛋 1个柳州老牌干捞：碎肉、花生、蒜和辣油拌粉，分量偏小。它和深圳常见汤粉不是一路味道，作为本轮主食。
  2. 杨姐深巷酸 · 青芒果或萝卜酸 1小盒广西酸嘢负责解腻，只选一种。先试味再决定辣椒盐放多少。
  3. 张飞 / 韦韦木薯糖水 · 木薯羹 1碗木薯软糯、甜汤解辣。哪家顺路且排队短就吃哪家，不为同类糖水重复排队。
  4. 金团子 · 糯米糍 2个选奶油芋泥或当日现做口味，一人一个。属于本地糯叽叽糕点，比跨城也能吃到的连锁小吃更值得。
  5. 蒙记老牌豆浆 · 22:30后再决定看完喷泉重新饿了，再点半糖豆浆＋油条/蛋散；当天吃饱就取消，不专程硬塞。
建议顺序：大华干捞 → 杨姐酸嘢 → 茶麸洗头 → 木薯糖水 → 金团子 → 江边喷泉。已删除不够柳州本地的跨城连锁小吃。
